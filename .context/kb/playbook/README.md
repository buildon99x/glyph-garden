# Playbooks

Playbooks describe repeatable project workflows. They should be short enough to use during a coding session.

## Template

```md
# Playbook: Workflow Name

## When to Use

Use this when...

## Steps

1. Do the first step.
2. Run the verification.
3. Record the result.

## Verification

What proves the workflow succeeded?

## Related Knowledge

Links to ADRs, lessons, docs, or source files.
```
