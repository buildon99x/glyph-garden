# Knowledge Archive

Use this directory for retired knowledge that should remain searchable but should not guide active work.

Archive candidates:

- superseded ADRs,
- obsolete plans,
- stale lessons,
- retired playbooks,
- historical raw notes that are no longer active but may be useful later.

## Rules

- Do not archive current operating rules.
- Prefer moving whole files over copying content.
- Add a short note at the top of archived files explaining why they were archived.
- Keep active README indexes free of archived items unless the archived item is important history.

## Naming

Keep original filenames when moving files here. If needed, group by source area:

```text
.context/kb/archive/adr/
.context/kb/archive/lrn/
.context/kb/archive/playbook/
```
