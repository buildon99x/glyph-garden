# Architecture Decision Records

ADR files record decisions that future contributors and agents must respect.

## Template

```md
# ADR NNNN: Title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD
- Owners: Name or role

## Context

What problem or tradeoff forced this decision?

## Decision

What did we choose?

## Consequences

What becomes easier, harder, or forbidden because of this decision?

## Alternatives Considered

What else was considered, and why was it not chosen?
```
