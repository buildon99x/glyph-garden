# Changelog

All notable changes to Glyph Garden will be documented in this file.

This project uses Conventional Commits and Release Please to prepare changelog updates through release pull requests.

Only player-facing product changes belong here. Development environment setup, coding-agent instructions, GitHub workflow changes, and other repository operations are intentionally excluded.

## [0.1.0] - 2026-06-09

### Added

- Built the initial Glyph Garden replayable puzzle prototype.
- Added glyph placement, scoring, goals, world rules, runes, and a five-garden run flow.
- Added candidate hints, last-move feedback, hover previews, and goal requirement indicators to make play easier to understand.
