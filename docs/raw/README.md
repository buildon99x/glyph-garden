# Raw Materials

Use this directory for unprocessed source material that supports specs, plans, ADRs, or lessons learned.

Examples:

- command logs,
- copied issue or PR context,
- debugging notes,
- external reference excerpts,
- screenshots or exported data references.

## Rules

- Redact secrets, credentials, private messages, and personal data before committing.
- Prefer dated filenames: `YYYY-MM-DD-topic.md`.
- Add a short note at the top explaining where the material came from.
- Link raw files from a spec, plan, ADR, or lesson when they are used as evidence.
