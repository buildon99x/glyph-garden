# Specs

Specs describe what the product or system should do.

## Template

```md
# Spec: Title

- Status: Draft | Accepted | Superseded
- Date: YYYY-MM-DD
- Owner: Name or role

## Problem

What user or project problem does this solve?

## Goals

- Goal 1
- Goal 2

## Non-goals

- Explicitly out of scope

## Requirements

- Requirement 1
- Requirement 2

## Acceptance Criteria

- Observable condition that proves the spec is implemented

## Open Questions

- Question
```
